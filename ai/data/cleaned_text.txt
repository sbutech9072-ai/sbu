4. What SBU TECH does
SBU TECH is a senior-led software engineering studio that works with businesses to design, build and scale production software. Its public positioning focuses on robust architecture, 
practical engineering, reliable delivery and direct technical collaboration.
Custom Web Application Development: Production web platforms, SaaS products, internal business systems and real-time data applications. Common technologies include Next.js, 
React, TypeScript, Node.js and PostgreSQL.
Cloud Architecture & DevOps: Cloud infrastructure, AWS and GCP environments, Kubernetes, Terraform, Docker, CI/CD, monitoring, reliability and deployment automation.
Mobile App Engineering: iOS and Android applications using React Native, Expo or Flutter, including mobile integrations and offline-capable experiences.
AI & Machine Learning Solutions: Private Retrieval-Augmented Generation (RAG), document search, hybrid keyword and vector retrieval, LLM workflows, evaluation and 
FastAPI integration.
UI/UX Product Design & Design Systems: Product workflows, interface design, Figma prototypes, reusable components, design tokens and accessibility-focused design.
5. How a project typically works
Stage

1. Discovery & Planning

Create user experiences and build modular software in iterative engineering sprints.

Run functional, integration, performance, security and accessibility checks relevant to the 
project.
5. Deployment & Ongoing Support
Deploy the solution, monitor production, hand over source code and documentation, and 
provide agreed support.
6. What to collect from a prospective client
• Name, organisation and work email; phone number only if the visitor chooses to provide it.
• What they want to build or improve, and the business problem they need to solve.
• Target users, required features, platforms, integrations and relevant data sources.
• Security, privacy or compliance requirements; existing technology or infrastructure.
• Preferred timeline, budget range if available, and how success will be measured.

8. Frequently asked questions
What is SBU TECH?
SBU TECH is a senior-led software engineering studio that designs, builds and scales web platforms, cloud infrastructure, mobile applications and private AI systems.
What services does SBU TECH provide?
Custom web applications; cloud architecture and DevOps; mobile app engineering; AI and machine-learning solutions, including RAG; and UI/UX design systems.
How can I request a quote?
Use Get a Quote / Request Project Quote or the Contact page. Share your name, work email, project subject and a short description of what you want to build. A phone number is optional.
What information should I prepare?
Explain the business problem, project goal, target users, key features, platforms, integrations, data sources, security needs, timeline and budget range if known. Never send passwords, API 
keys or private credentials in chat.
How do I log in to the Client Portal?
Visit https://www.sbutech.com/login, choose Login, enter your registered email and password, then select Sign In as Client. The portal is described as providing sprint boards, staging links 
and invoices.
How do I register?
On the Client Portal, choose Register and follow the live form. If access or approval is unclear, email contact@sbutech.com. A full registration-approval or password-reset guide is not 
published.
What are Owner and Admin access?

Who owns SBU TECH?
The About page identifies Bidhan Shaha Dhrubo as Main Owner, and Utsob Saha and Borson Saha as Co-Owners and founding partners.
Can clients see project progress and invoices?
Yes. The Client Portal page says authorised clients can view active sprint boards, staging links and invoices after signing in.
What is my contract number or project status?
Only answer from a securely connected contract or project record after checking user authorisation. Otherwise direct the user to their SBU TECH representative. Never invent a contract 
number, fee, status or deadline.
9. Rules for the website AI assistant
• Answer from this knowledge base and approved connected records only. Do not invent owners, prices, phone numbers, contract numbers, project results or policies.
• Reply in the language used by the visitor where possible (English or Bangla). Keep answers concise, polite and practical.
• For project enquiries, ask only for the information needed to understand the request: project goal, type of solution, key features, integrations, timeline and a work email for follow-up.
• Never ask a visitor to share passwords, one-time codes, API keys, private keys, payment-card details or other secrets in chat.
• Do not reveal another client's project, invoice, staging URL, contact details or contract information. Confirm authentication and authorisation before account-specific answers.
• If information is missing or uncertain, say so clearly and direct the visitor to contact@sbutech.com.
• Do not claim that SBU TECH is SOC 2 or HIPAA certified based only on website references to readiness or security controls.
